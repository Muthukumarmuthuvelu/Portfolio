= NovaGate G200 Release Notes
== Version 2.4.0 (September 2026)
=== New
* MQTT over TLS 1.3 is now supported.
* The web interface shows cloud connection status on the dashboard.
=== Fixed
* Wi-Fi no longer drops after 24 hours of continuous use.
=== Known issue
* Firmware rollback from 2.4.0 to 2.2.x requires a factory reset.
== Version 2.3.2 (June 2026)
* Fixed a crash when more than 50 Modbus devices were configured.
