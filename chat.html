Documentation Assistant

A working demo of an AI-ready documentation assistant. It answers only from the indexed sources, shows where each answer came from, and says so when it cannot find one.

Hello. Ask me about the sample NovaGate G200 documentation or about AI-ready documentation practices.

Indexed sources

How it works

  1. Sources in many formats are converted to text and split into passages.
  2. Your question retrieves the best-matching passages.
  3. An AI model writes the answer from those passages only.
  4. Sources are shown so every answer can be checked.
The NovaGate G200 is a fictional product used for this demo.
